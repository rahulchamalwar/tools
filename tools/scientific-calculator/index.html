Scientific Calculator

Calculate expressions with common scientific functions and constants. Choose degrees or radians for trigonometry; calculations run locally in your browser.

How to use this tool

  1. Enter an expression such as sin(30) + sqrt(16).
  2. Choose degrees or radians for trigonometric functions.
  3. Select Calculate to see the result.

Features

  • sin, cos, tan and inverse trigonometric functions
  • Powers, roots, logarithms, factorial and constants
  • Expression parsing without JavaScript evaluation

Frequently asked questions

Is this tool free to use?

Yes. Open Lab Tools is free to use, with no account required.

Are my files uploaded?

File tools process your selected files in your browser. The files are not intentionally sent to an Open Lab Tools server.

Can I use this tool on my phone?

Yes. The page is responsive and works in current mobile and desktop browsers.
