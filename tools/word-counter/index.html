Word Counter

Paste or type text to see live counts for words, characters, sentences, paragraphs and estimated reading time.

How to use this tool

  1. Paste or type text in the editor.
  2. Review the live counts beneath the field.
  3. Copy the text or download it as a TXT file.

Features

  • Live word and character counts
  • Sentence, paragraph and reading-time estimate
  • Copy and TXT download

Frequently asked questions

Is this tool free to use?

Yes. Open Lab Tools is free to use, with no account required.

Are my files uploaded?

File tools process your selected files in your browser. The files are not intentionally sent to an Open Lab Tools server.

Can I use this tool on my phone?

Yes. The page is responsive and works in current mobile and desktop browsers.
