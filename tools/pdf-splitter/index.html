PDF Splitter

Create separate PDFs from page ranges such as 1-3;4-6. Split files are created in your browser and downloaded individually or as one ZIP archive.

How to use this tool

  1. Choose a PDF file and check its page count.
  2. Enter page range groups separated by semicolons, such as 1-3;4-6.
  3. Select Split PDF and download the resulting PDFs.

Features

  • Separate PDF output for each range
  • Single-file or ZIP download
  • Pages remain vector-based and selectable

Frequently asked questions

Is this tool free to use?

Yes. Open Lab Tools is free to use, with no account required.

Are my files uploaded?

File tools process your selected files in your browser. The files are not intentionally sent to an Open Lab Tools server.

Can I use this tool on my phone?

Yes. The page is responsive and works in current mobile and desktop browsers.
