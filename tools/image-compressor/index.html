Image Compressor

Reduce an image’s file size locally with a quality slider. The output is WebP for compact size, while the original remains untouched.

How to use this tool

  1. Select or drop a JPG, PNG or WebP image.
  2. Adjust the quality slider and choose Compress image.
  3. Compare sizes, preview the result and download it.

Features

  • Browser-side canvas processing
  • Quality slider and saved-size percentage
  • No intentional upload of selected files

Frequently asked questions

Is this tool free to use?

Yes. Open Lab Tools is free to use, with no account required.

Are my files uploaded?

File tools process your selected files in your browser. The files are not intentionally sent to an Open Lab Tools server.

Can I use this tool on my phone?

Yes. The page is responsive and works in current mobile and desktop browsers.
