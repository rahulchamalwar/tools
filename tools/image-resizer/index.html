Image Resizer

Set new dimensions or a percentage scale and keep the original image ratio if desired. Image resizing runs in your browser.

How to use this tool

  1. Select a JPG, PNG or WebP image.
  2. Enter the desired width, height or scale percentage.
  3. Preview and download the resized image.

Features

  • Width and height controls
  • Optional aspect-ratio lock
  • Browser-side image processing

Frequently asked questions

Is this tool free to use?

Yes. Open Lab Tools is free to use, with no account required.

Are my files uploaded?

File tools process your selected files in your browser. The files are not intentionally sent to an Open Lab Tools server.

Can I use this tool on my phone?

Yes. The page is responsive and works in current mobile and desktop browsers.
