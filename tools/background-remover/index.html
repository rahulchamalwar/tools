Background Remover

Make a uniform background transparent with a local color selection tool. It works best with simple, evenly colored backgrounds and is not AI subject segmentation.

How to use this tool

  1. Choose a JPG, PNG or WebP image.
  2. Adjust the background color tolerance.
  3. Preview and download the transparent PNG.

Features

  • Runs locally in your browser
  • Tolerance control for near-solid backgrounds
  • Transparent PNG export

Frequently asked questions

Is this tool free to use?

Yes. Open Lab Tools is free to use, with no account required.

Are my files uploaded?

File tools process your selected files in your browser. The files are not intentionally sent to an Open Lab Tools server.

Can I use this tool on my phone?

Yes. The page is responsive and works in current mobile and desktop browsers.
