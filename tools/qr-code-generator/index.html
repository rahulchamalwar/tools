QR Code Generator

Turn a link or short message into a QR code that can be scanned by a phone camera. QR content is generated in your browser.

How to use this tool

  1. Select a content type and fill its fields.
  2. Choose Generate QR code to preview it.
  3. Download the PNG or copy the encoded text.

Features

  • QR preview and PNG download
  • URL, text, phone, email and Wi-Fi formats
  • Browser-side generation

Frequently asked questions

Is this tool free to use?

Yes. Open Lab Tools is free to use, with no account required.

Are my files uploaded?

File tools process your selected files in your browser. The files are not intentionally sent to an Open Lab Tools server.

Can I use this tool on my phone?

Yes. The page is responsive and works in current mobile and desktop browsers.
