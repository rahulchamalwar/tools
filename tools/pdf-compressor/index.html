PDF Compressor

Rebuild a PDF from rendered page images to reduce file size. This lossy process may remove selectable text, links, form fields and vector detail; check the downloaded result before sharing.

How to use this tool

  1. Choose a PDF file from your device.
  2. Select output quality and resolution.
  3. Compress, compare actual file sizes and download if the result suits your needs.

Features

  • Local browser processing
  • Actual input and output sizes shown
  • Transparent note about text and vector flattening

Frequently asked questions

Is this tool free to use?

Yes. Open Lab Tools is free to use, with no account required.

Are my files uploaded?

File tools process your selected files in your browser. The files are not intentionally sent to an Open Lab Tools server.

Can I use this tool on my phone?

Yes. The page is responsive and works in current mobile and desktop browsers.
