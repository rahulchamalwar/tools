Currency Converter

Convert between 18 common currencies using daily reference exchange rates. The amount and result stay in this page; the rate provider is contacted to fetch current rate data.

How to use this tool

  1. Enter an amount and choose the source and target currencies.
  2. Select Convert to fetch the latest available daily rate.
  3. Review the converted amount, rate and rate date.

Features

  • 18 common world currencies
  • Rate and effective date displayed
  • No API key required

Frequently asked questions

Is this tool free to use?

Yes. Open Lab Tools is free to use, with no account required.

Are my files uploaded?

File tools process your selected files in your browser. The files are not intentionally sent to an Open Lab Tools server.

Can I use this tool on my phone?

Yes. The page is responsive and works in current mobile and desktop browsers.
